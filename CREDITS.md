# Credits

Every character, enemy, Elite, Caelith and NPC model, every texture, sound and music track of Skyshard: Echoes of the
Wild is generated by code at run time (`src/anim`, `src/visual`, `src/audio`, `src/data/music.ts`). Optional CC0-1.0
files listed in `public/assets/manifest.json` replace the sound or prop of the same id; each one used is recorded in
the Assets table. Swapped-in external models (`src/data/visualManifest.ts`) must be recorded there too.

This file and `src/data/credits.ts` hold the same entries (`tests/unit/credits.test.ts` checks them).
